Titanic Survival Prediction API

A machine learning API that predicts passenger survival on the Titanic using a Random Forest classifier, packaged in Docker and published on Docker Hub so anyone can run it with a single command

Python Docker FastAPI Scikit-learn Pandas
Try Live Demo View on GitHub View on Docker Hub View Notebook

Project Overview

Business Context: Taking a trained model off my own computer and turning it into a service that other people and applications can actually use.

In this project I trained a machine learning model from scratch, containerized it, and published it to Docker Hub. The model is trained inside a Jupyter Docker container, then served from a separate, lighter Docker container using FastAPI.

Anyone with Docker can pull the image and get survival predictions for a Titanic passenger through a simple API, without installing Python or any libraries.

What This Demonstrates

Problem-Solving Process

  5. Debugging: Found and fixed several things in the instructions that broke on newer versions, like missing values that silently stopped getting filled in with pandas 3

API Endpoints

GET /

Health check that shows whether the model loaded and its accuracy.

POST /predict

Send one passenger's details and get back survived or not, the survival probability, and a confidence level.

POST /predict-batch

Send a list of passengers and get a prediction for each one.

GET /model-info

Model type, training date, accuracy, and the features it uses.

Dataset

The model is trained on Kaggle's Titanic train.csv (891 passengers). The API takes 7 inputs:

  • Pclass - Passenger class (1, 2, 3)
  • Sex - male or female
  • Age - Age in years
  • SibSp - Siblings/spouses aboard
  • Parch - Parents/children aboard
  • Fare - Ticket price
  • Embarked - Port: Cherbourg, Queenstown, or Southampton

How It Works

  1. Training Container - Jupyter Lab image with pandas, scikit-learn, and the plotting libraries, with my project folder mounted as a volume
  2. Data Cleaning - Fill in missing ages, fares, and ports
  3. Feature Engineering - Family size, traveling alone, title from the name, age group, and fare group
  4. Model Training - Random Forest with 20% of passengers held out for testing
  5. Saving the Model - Model, encoders, and metadata saved with joblib and copied to the serving folder
  6. Serving Container - Slim Python image running FastAPI, with a health check and a non-root user
  7. Publishing - Tagged as v1.0 and latest, and pushed to Docker Hub

Key Results

  • Accuracy: about 82% (0.8156) on 179 test passengers
  • Live demo: the same Docker image runs on my server, so anyone can try the model from the demo page
  • One-command setup: docker run -p 8000:8000 vfoster2docker/titanic-survival-api
  • Input checking: bad values like "Male" with a capital M or class 4 get a clear error instead of a wrong prediction
  • Up to date: Python 3.13, pandas 3.0, scikit-learn 1.9, and the current Jupyter images
